# 🌟 Timeline Project - Stage 1

This is the starter template for the Timeline Visualization Project.

## Features in this stage:

- `index.html` includes:
  - `<header>` with a logo and theme toggle button
  - `<nav>` placeholder for filters (currently empty)
  - `<section id="timeline">` for rendering event markers
  - `<div id="modal">` for future pop-up content
  - Semantic structure with `<main>`, `<article>`, `<figure>`

## Next Steps (for Stage 2+):

- Add dynamic event rendering
- Implement filter functionality
- Enable modal popups for event details
- Improve styling and accessibility
